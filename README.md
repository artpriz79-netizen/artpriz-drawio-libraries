## Важно

- `Середина кубка` разбита на 4 небольшие библиотеки, чтобы GitHub/draw.io стабильно их загружал.
- `ВЕРХ КУБКА` разбит на 2 части.
- `ТРОЙКИ` разбиты на 2 части.
- Исходные файлы `ВЕРХ КУБКА.drawio` и `Комплектующие для кубков.drawio` были идентичны по содержимому, поэтому отдельная дублирующая библиотека комплектующих не создавалась.
- Новые элементы можно добавлять: обновите соответствующий XML-файл в GitHub под тем же именем — ссылки запуска менять не потребуется.
