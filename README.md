# ArtPriz draw.io libraries

Готовый набор библиотек для визуальной сборки кубков в draw.io.

## Быстрый запуск

- [Открыть конструктор со всеми библиотеками ArtPriz](https://artpriz79-netizen.github.io/artpriz-drawio-libraries/)

Публичный адрес постоянный. Список подключаемых библиотек находится в `index.html`.

## Подключённые библиотеки

- `libraries/01-fony.xml`
- `libraries/02-ДЕТАЛІ НА ПІДСТАВКУ.xml`
- `libraries/03-ЧАШИ.xml`
- `libraries/Ножки на основу`
- `libraries/07-detalki.xml`
- `libraries/08-troyki-a.xml`
- `libraries/09-КОМПЛЕКТУЮЧІ.xml`

## Библиотека № 3 — ЧАШИ

`libraries/03-ЧАШИ.xml` — новая библиотека draw.io для чаш. Пока она пуста: изображения чаш ещё не добавлены. Библиотека подключена к конструктору и готова к наполнению.

## Обновление деталей

- Обновляйте соответствующий XML-файл под тем же именем — публичную ссылку менять не потребуется.
- Формат библиотеки: `<mxlibrary>` с JSON-массивом элементов внутри.
- Существующая библиотека `libraries/Ножки на основу` подключена по её фактическому имени без расширения.
